# Habits Trainer

Progressive habit coaching app for iPhone, built with Expo + React Native (SDK 54).

Set a big habit goal, choose a small starting point, and build up little by little.

## What’s implemented

| Phase | Status | Focus |
|------:|:------:|-------|
| 0 | ✅ | Foundation |
| 1 | ✅ | Habit goal creation |
| 2 | ✅ | Weekly prescription + logging |
| 3 | ✅ | Progression engine |
| 4 | ✅ | Coaching + motivation |
| 5 | ✅ | Multi-habit load management |
| 6 | ✅ | Reminders, scheduling & polish |
| 7 | ✅ | Templates, insights & backup |

## Highlights

- Start small → weekly prescriptions → level up / hold / downshift
- Coaching metrics, hard-day fallbacks, weekly reflection ritual
- Local reminders with preferred days/times
- Habit templates (fitness, reading, meditation, language, deep work)
- Insights + JSON backup/restore

## Requirements

- Node.js 20+
- Expo Go on iPhone (**SDK 54** App Store build)

## Getting started

```bash
npm install
npm start
```

Useful scripts:

```bash
npm run typecheck
npm test
npm run ios
```
